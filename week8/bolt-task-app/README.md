# Student Task Manager – Bolt Version

## Stack
React + Vite + Supabase + Tailwind CSS

## Description
This version of the Student Task Manager application was generated using the Bolt AI app generator. The application allows users to create, view, update, and delete study tasks.

Each task contains:
- title
- description
- deadline
- status
- created_at

## Installation

Install dependencies:

npm install

## Run

Start development server:

npm run dev

Open browser:

http://localhost:5173

## Notes

This version was generated using Bolt.new and slightly adjusted manually.
Supabase is used as the backend database service.
